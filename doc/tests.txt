# Чек-лист тестирования

---

## 1. Запуск и инфраструктура

### 1.1 Single instance| 1.1.1 | Запустить утилиту, затем запустить вторую копию | Вторая показывает сообщение "Already running" и закрывается |
| 1.1.2 | Закрыть первую, запустить снова | Запускается нормально |
| 1.1.3 | Убить первую через Task Manager, запустить снова | Запускается нормально (AbandonedMutexException) |

### 1.2 Exit codes| 1.2.1 | Успешная обработка папки | `.bat` завершается без сообщения об ошибке |
| 1.2.2 | Пустая папка (нет файлов) | `.bat` показывает "exited with error code: 1" |
| 1.2.3 | Намеренная ошибка в Settings.psd1 | Показываются ошибки валидации, exit 1 |
| 1.2.4 | Удалить Settings.psd1 | Сообщение "not found", exit 1, `.bat` ловит код |

### 1.3 Валидация конфига| 1.3.1 | `AvifQuality = 150` | Ошибка "must be 0-100" |
| 1.3.2 | `AvifQuality = -1` | Ошибка "must be 0-100" |
| 1.3.3 | `DeleteOriginals = 5` | Ошибка "must be 0 or 1" |
| 1.3.4 | `StaticPixFmt = "rgb24"` | Ошибка "must be yuv420p or yuv444p" |
| 1.3.5 | Удалить секцию `Avifenc` целиком | Ошибка "Missing section: Avifenc" |
| 1.3.6 | Корректный конфиг | Без ошибок, продолжает работу |

## 2. Зависимости

### 2.1 Модель *Checked| 2.1.1 | Все `*Checked = 1` в `state.psd1`, инструменты установлены | Проверки проходят мгновенно |
| 2.1.2 | `AvifencChecked = 1`, но avifenc удалён из PATH | Сброс флага в 0, показ диалога установки |
| 2.1.3 | `FFmpegChecked = 0`, ffmpeg установлен | Показ диалога, после "Install" → проверка → флаг = 1 |
| 2.1.4 | Удалить `state.psd1` | Создаётся заново с дефолтами, все проверки запускаются |
| 2.1.5 | `Gif2WebpChecked = 0`, gif2webp не установлен | Диалог установки, запуск `gif2webp-Install.ps1` |

### 2.2 PowerShell 7| 2.2.1 | pwsh установлен | Проверка проходит, продолжает |
| 2.2.2 | pwsh не установлен | Диалог winget install |

### 2.3 Install-скрипты| 2.3.1 | Запустить `avifenc-Install.ps1` из `installers/` | Устанавливает в `tools\libavif`, обновляет PATH |
| 2.3.2 | Запустить `ffmpeg-Install.ps1` из `installers/` | Устанавливает в `tools\ffmpeg` |
| 2.3.3 | Запустить `gif2webp-Install.ps1` из `installers/` | Устанавливает в `tools\libwebp` |
| 2.3.4 | Ошибка скачивания (отключить сеть) | Сообщение об ошибке, temp cleanup, exit 1 |

## 3. Ввод и навигация

### 3.1 Input path| 3.1.1 | Drag & drop папки на `.bat` | Папка принята, показано "Folder received via argument" |
| 3.1.2 | Drag & drop JPG файла | Single-file mode |
| 3.1.3 | Drag & drop .txt файла | Переход к ручному вводу папки |
| 3.1.4 | Drag & drop несуществующего пути | Переход к ручному вводу |
| 3.1.5 | Ручной ввод папки | Принимает корректный путь |
| 3.1.6 | Ручной ввод пустой строки | Ошибка "Path cannot be empty" |
| 3.1.7 | Путь с пробелами и спецсимволами | Корректная обработка |

### 3.2 Processing mode с auto-timeout| 3.2.1 | Не нажимать ничего 3 секунды | Автовыбор Quick start, видно обратный отсчёт |
| 3.2.2 | Нажать Enter сразу | Немедленный Quick start |
| 3.2.3 | Ввести "1" | Custom settings mode |
| 3.2.4 | Ввести "X" (невалидно) | Ошибка, повтор с новым отсчётом |
| 3.2.5 | Начать вводить, потом ждать | Таймер сбрасывается при каждом нажатии |

### 3.3 Resume plan| 3.3.1 | Есть `EncodingPlan_Resume.clixml` в папке | Диалог "Resume / Start over" |
| 3.3.2 | Выбрать Resume | Загрузка плана, продолжение обработки |
| 3.3.3 | Выбрать Start over | Удаление старого плана, новый анализ |

## 4. Анализ файлов (AnalyzeFiles.ps1)

### 4.1 Extension table| 4.1.1 | Папка с JPG + PNG + GIF + TXT + AVIF | Таблица: Supported / Already AVIF / Not supported |
| 4.1.2 | Папка только с AVIF | "No supported files found" |
| 4.1.3 | Папка с > 10 неподдерживаемых расширений | Строка "... +N ext (M files)" |

### 4.2 Analysis box| 4.2.1 | Папка с файлами | Бокс "Analyzing N files / Threads: M" |
| 4.2.2 | После анализа | Бокс "Analysis complete: N files ready" |

### 4.3 Pre-filter| 4.3.1 | Файл 0 байт | Skipped (ZeroBytes) |
| 4.3.2 | Файл < MinProcessSizeKB | Skipped (TooSmall) |
| 4.3.3 | Файл с уже существующим .avif рядом | Skipped (OutputExists) |
| 4.3.4 | Single-file mode с существующим output | НЕ пропускается (OutputExists не проверяется) |

### 4.4 Format detection| 4.4.1 | JPG файл | `.NET` decode, opaque, Success |
| 4.4.2 | PNG без alpha | `.NET` decode, HasAlpha = false |
| 4.4.3 | PNG с alpha (RGBA) | HasAlpha = true |
| 4.4.4 | PNG indexed с прозрачностью | HasAlpha = true (pixel sampling) |
| 4.4.5 | TIFF без alpha | HasAlpha = false |
| 4.4.6 | TIFF с alpha | HasAlpha = true |
| 4.4.7 | BMP | `.NET` decode, opaque |
| 4.4.8 | Static GIF (1 frame) | Binary parser, FrameCount = 1, IsAnimated = false |
| 4.4.9 | Animated GIF (>1 frame) | Binary parser, IsAnimated = true, alpha НЕ проверяется |
| 4.4.10 | Static WebP (VP8) | Binary parser, IsAnimated = false |
| 4.4.11 | Static WebP (VP8L, с alpha) | HasAlpha = true |
| 4.4.12 | Animated WebP | IsAnimated = true → skipped (AnimatedWebP) |
| 4.4.13 | Повреждённый файл | Попадает в suspicious → decode test → `_corrupt` |
| 4.4.14 | Файл с нечитаемым форматом, но декодируемый | UnsupportedMetadata → warnings.log |

### 4.5 Corrupt handling| 4.5.1 | Повреждённый JPG | Перемещён в `_corrupt/`, запись в `corrupt.log` |
| 4.5.2 | Повреждённый GIF | Перемещён в `_corrupt/` |
| 4.5.3 | Папка `_corrupt` уже существует | Файлы добавляются, коллизии имён обрабатываются |

| 5.1.4 | BMP → план | TaskType = AvifPipe, Phase = 2 |

| 5.1.6 | Static WebP → план | TaskType = AvifPipe, Phase = 2 |
| 5.1.7 | Static GIF → план | TaskType = AvifPipe, Phase = 2 |

## 6. Кодирование (CompressPhotos.ps1)

### 6.1 AvifDirect| 6.1.1 | JPG → AVIF | Успех, .avif создан, оригинал в корзине (если Delete=1) |
| 6.1.2 | PNG opaque → AVIF | Успех |
| 6.1.3 | PNG alpha → AVIF | Успех, alpha сохранён |
| 6.1.4 | AVIF больше оригинала | Skip, .avif удалён, оригинал сохранён |

### 6.2 AvifPipe| 6.2.1 | BMP → AVIF | Успех через ffmpeg pipe |
| 6.2.2 | TIFF → AVIF | Успех |
| 6.2.3 | Static WebP → AVIF | Успех |
| 6.2.4 | Static GIF → AVIF | Успех через PNG pipe |

### 6.3 Gif2Webp| 6.3.1 | Animated GIF → WebP | Успех через gif2webp |
| 6.3.2 | Ошибка gif2webp | Failure, нет fallback |

### 6.4 Fallback| 6.4.1 | Повреждённый JPG, avifenc падает | Fallback: ffmpeg → temp → avifenc |
| 6.4.2 | Fallback тоже падает | Failure, записывается в лог |
| 6.4.3 | Промежуточный temp-файл | Удаляется после fallback |

### 6.5 Параллелизм| 6.5.1 | 10+ файлов | Несколько задач выполняются параллельно |
| 6.5.2 | Проверить Active counter | Показывает реальное число запущенных |
| 6.5.3 | 1 файл (single mode) | 1 задача, без параллелизма |

### 6.6 Timeout| 6.6.1 | `TimeoutSec = 5`, большой файл | Timeout, failure, процессы убиты |
| 6.6.2 | `TimeoutSecSingleFile = 0` | Без таймаута, ждёт до конца |

### 6.7 Progress| 6.7.1 | Обработка 20+ файлов | Прогресс-бар обновляется плавно |
| 6.7.2 | Длительная обработка одного файла | Прогресс обновляется (Active: 1) |

## 7. Stop / Resume

### 7.1 Q-stop| 7.1.1 | Folder mode, нажать Q | Останавливается, сохраняет resume plan |
| 7.1.2 | Single-file mode, нажать Q | Ничего не происходит (Q игнорируется) |
| 7.1.3 | Resume plan создан | Файл `EncodingPlan_Resume.clixml` в папке-источнике |

### 7.2 Resume| 7.2.1 | Запустить снова ту же папку | Предложение Resume |
| 7.2.2 | Resume: оставшиеся файлы | Обрабатываются только не обработанные ранее |
| 7.2.3 | Успешное завершение после resume | Resume plan удаляется |

## 8. Логирование
| 8.1 | Успешная обработка без fallback | Лог НЕ создан (если `DebugLogSingleFile = 0`) |
| 8.2 | Успешная обработка c fallback | Лог создан, запись [SUCCESS] с fallback |
| 8.3 | Ошибка кодирования | Лог создан, запись [FAILED] с stderr |
| 8.4 | Skip (размер не уменьшился) | Запись [SKIP] в логе |
| 8.5 | Single file + `DebugLogSingleFile = 1` | Лог всегда создаётся |
| 8.6 | Нажать "1" для открытия лога | Лог открывается в текстовом редакторе |
| 8.7 | Crash (trap) | `crash_*.log` в `logs/`, stack trace если `DebugMode = 1` |

## 11. Edge cases
| 11.1 | Папка с 1 файлом (folder mode) | Работает как folder mode, не как single |
| 11.2 | Файл только для чтения | Кодирование успешно, удаление может не сработать |
| 11.3 | Очень длинный путь (> 200 символов) | Корректная обработка |
| 11.4 | Имя файла с кириллицей/Unicode | Корректная обработка |
| 11.5 | Имя файла с пробелами | Корректная обработка |
| 11.6 | Папка с 10000+ файлов | Работает, прогресс-бар адаптируется |
| 11.7 | Диск почти заполнен | Ошибки кодирования, не crash |
| 11.8 | Файл удалён между анализом и кодированием | Skip, warning в логе |
| 11.9 | Файл изменён между анализом и кодированием | Skip, warning в логе |
